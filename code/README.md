# 有限核验的算法与范围

运行环境为 **Python 3.10 或更新版本**，只使用标准库，不需要安装依赖，也不访问网络。从仓库根目录运行：

```console
python reproduce.py
```

入口会重新计算全部项目，写入 `results/verification.json` 和 `results/denominator_comparison.json`。任一数值检查、预期计数或程序执行失败时，退出码为非零。入口用自身所在目录定位代码和结果，因此也可以从其他目录用脚本路径运行。

如需保留克隆仓库的干净状态，可将结果写到仓库外。显式传入的目录相对于当前工作目录解释：

```console
python reproduce.py --output-dir ../remote-reproduction
```

这些是辅助审查证明的有限计算，**不能替代对任意分拆的无限证明，不能确认首次性，也不构成一般 plethysm 正组合问题的解决**。

## 1. 分拆与钩长条件

递归枚举每个 $3\le w\le15$ 的全部分拆。对零起始单元格 $(i,j)$，计算

$$
h_{ij}=\mu_i-j+\#\{r>i:\mu_r>j\}.
$$

逐一检查每个整数 $2\le d\le\max h_{ij}+1$，是否至少有两条钩长不能被 $d$ 整除。总计 **680 个分拆、6542 对分拆与除数**。大于最大钩长的除数不整除任何钩长，因此无需继续扩大该有限检查的除数范围。

## 2. 精确有限差分消去

对 $3\le w\le100$，用 Python 任意精度整数直接计算

$$
\sum_{0\le s<w/2}(-1)^s\binom ws(w-2s)^{w-2}=0.
$$

共 **98 个等式**；没有浮点误差或数值容差。

## 3. 两种算法核对 SL2 系数

第一种算法直接枚举形状为 $\mu$、取值于 $0,\ldots,h$ 的半标准 Young 表：行弱增、列严格增。每个表 $T$ 贡献权

$$
\sum_{c\in\mu}(2T(c)-h).
$$

记权为 $r$ 的表数为 $C_r$，则对应输出标签 $k\ge1$ 的 SL2 重数为 $C_{k-1}-C_{k+1}$。这里 $k$ 对应最高权 $k-1$ 的不可约表示。

第二种算法由钩长公式独立计算。本节代码的行列索引从 0 开始，因此令 $b=\sum_{i\ge0}i\mu_i$；这与证明正文从 1 开始索引的 $b(\mu)$ 相同。置 $H(t)=\prod_c(1-t^{2h_c})^{-1}$、$G_n=[t^n](t-t^{-1})H(t)$，其中 $H$ 的负次数系数为零。展开钩内容分子，计算

$$
\sum_{S\subseteq\mu}(-1)^{|S|}
G_{k+(w-2|S|)h-2b-2\sum_{(i,j)\in S}(1+j-i)}.
$$

$H$ 的系数使用整数动态规划求出。该算法不调用表枚举。范围为所有 $3\le w\le7$、$0\le h\le5$、$1\le k\le wh+1$，共 **41 个分拆、246 个特化、3771 个系数**；直接枚举累计访问 **33707 个完整表**。这些计数包括没有合法表的特化。

另有一组 **174 个交叉核对**：全部 $1\le w\le6$、$1\le h\le\lfloor12/w\rfloor$、$q=2,3$。直接表枚举的相邻权差求值，与计算生成函数时使用的钩内容算法相比较。

## 4. 分母与周期上界比较

用升幂系数数组表示整数多项式，逐次乘入 $1-z^a$，再做精确整数多项式长除法。对正文列出的四个分拆，核验新的纯 $z$ 分母整除旧分母。记录分母的 $z$ 次数以及指数的最小公倍数。

这些值给出递推阶数和固定输出权下最终准多项式周期的**上界**，没有证明是最小分母、最小递推阶数或最小周期，也没有测量算法运行加速。

## 5. 二元符号例子

对[原论文 Table 1](https://arxiv.org/html/2511.02649v2) 所列 $A_{(3)}=(q+q^4z^3)/((1-z^4)(1-q^2z^2)(1-q^3z))$，使用稀疏二元整数多项式进行交叉相乘，验证

$$
\frac{D_{(3)}Q_3 A_{(3)}}{(1-z^2)^2}
=q(1+z^2+z^4)(1-qz+q^2z^2).
$$

代码比较每一个单项式系数，残差必须恒为零。该检查不使用 SymPy 或其他计算机代数软件；它验证这一具体例子的符号恒等式。

## 6. 生成函数分母的整数与模特化

钩内容公式

$$
s_\mu(1,t,\ldots,t^h)
=t^b\frac{\prod_{(i,j)\in\mu}(1-t^{h+j-i+1})}
{\prod_{c\in\mu}(1-t^{h_c})}
$$

通过整数动态规划得到中间权及其相邻差，再计算 $[z^h]A_\mu(z,q)$。将候选分母

$$
\frac{\prod_c(1-z^{\delta h_c})}{(1-z)^2}
\prod_{\substack{1\le c\le w\\c\equiv w\pmod2}}(1-q^c z)
$$

与截断级数卷积。具体令 $N$ 为候选分母的 $z$ 次数、$N_{\rm old}$ 为粗分母的 $z$ 次数，程序选择截止值 $B=N-\mu_1-1$，检查 $B<h\le B+N_{\rm old}$ 的卷积系数是否为零。记录中的 `numerator_degree_bound` 表示此次检查采用的候选截止次数；这里不以有限零窗口单独证明其普遍充分性。逐个分拆的范围、截止值、最大 $h$ 和系数摘要都保存在结果 JSON 中。

- **382 个精确整数特化**：所有 $3\le w\le11$ 的分拆，$q=2,3$。精确仅指这两个数值上的整数运算，不能据此断言关于未指定 $q$ 的多项式恒等式。
- **504 个模筛查**：所有 $3\le w\le14$ 的分拆，$q=2$、模 $1000000007$。模零可能掩盖非零整数，证据强度低于精确整数核验。

结果中的 SHA-256 摘要取每个卷积系数的十进制表示和换行符依次串联后的字节，不包含本机目录或个人信息。运行耗时仅用于记录此次复现，不能用于声称新旧方法的性能差异。
