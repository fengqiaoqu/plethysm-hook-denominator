# 可复现结果

在仓库根目录运行 `python reproduce.py` 会重新生成本目录的两个 JSON 文件。运行需要 Python 3.10+，只用标准库；无需网络或第三方依赖。

使用 `python reproduce.py --output-dir ../remote-reproduction` 可把结果写到仓库外，避免复现时修改已跟踪的结果文件。

- [verification.json](verification.json)：每项核验、预期计数核对、各分拆特化、代码 SHA-256、Python 版本和本次运行元数据。`all_passed` 必须为 `true`，且命令退出码必须为 0。
- [denominator_comparison.json](denominator_comparison.json)：四个分拆的分母次数和准周期上界比较，并核验旧纯 $z$ 分母能被新分母精确整除。

预期结果为：

| --- | --- |
| 钩长条件 | 680 个分拆，6542 对分拆与除数 |
| 精确有限差分 | 98 个等式 |
| 直接表枚举与子集公式 | 246 个特化，3771 个系数，33707 个完整表 |
| 独立生成函数求值交叉核对 | 174 个 |

| 分拆 | 旧递推阶数上界 | 新递推阶数上界 | 旧周期上界 | 新周期上界 |

| $(4,2,1)$ | 60 | 38 | 840 | 24 |
| $(4,4,4,4)$ | 145 | 70 | 720720 | 420 |

这些是正文候选定理所给的**上界**，不是最小值，也不是运行速度测量。固定输出权的周期指最终准多项式的周期上界。有限计算不替代一般证明，不确认原创性、优先权或同行评审状态。算法和证据边界详见 [代码说明](../code/README.md)。
